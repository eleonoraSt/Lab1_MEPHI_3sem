# Техническое задание

Создать абстрактный класс "Множество" (ISet) и его реализацию &#150; изменяемое множество (MutableSet), использующую для хранения элементов бинарное дерево поиска (BinaryTree).
Реализовать тесты на корректную работу BinaryTree и MutableSet, консольный интерфейс для работы с ISet (MutableSet) и для тестов.
Протестировать скорость работы алгоритмов на объёмах данных в 10^4 &#150; 10^8 элементов, построить график зависимости времени выполнения от количества элементов.

## Бинарное дерево поиска

Узел бинарного дерева имеет не более двух потомков, где левый потомок меньше родителя, а правый &#150; больше родителя, повторяющихся элементов нет.

Сравнение между бинарным деревом поиска и бинарной кучей:

|Бинарное дерево поиска|Бинарная куча|
|----------------------|-------------|
|Хранение узлов на указателях|Хранение элементов в массиве|
|Память O(n), доп. расход на указатели O(2n)|Память O(n)|
|Вставка O(log<sub>2</sub>n)|Вставка O(log<sub>2</sub>n), до O(n) при реаллокации памяти|
|Поиск O(log<sub>2</sub>n)|Поиск O(n)|

Для m-арных деревьев при увеличении m уменьшается высота, и, соответственно, сложность алгоритмов вставки и поиска (O(log<sub>m</sub>n)), и увеличивается расход памяти на указатели (O(mn)).
При этом время работы алгоритмов бинарного дерева является достаточно малым: log<sub>2</sub>(10^8)&asymp;26,6.
Таким образом, реализация бинарного дерева даёт оптимальную сложность.

Хранение узлов (struct Node) реализовано при помощи уникальных указателей (UnqPtr).
Реализованы публичные методы:

- Вставка, проверка на вхождение, удаление элемента
- Методы комплекса map-reduce
- Сохранение в строку и чтение из строки в двух форматах:
    - Через пробел: "2 1 3"
    - В формате пар "родитель-потомок": "{2 : 1}, {2 : 3}"
- Выделение поддерева по корню
- Проверка на вхождение поддерева

Для методов, использующих последовательных проход по всем элементам дерева (map-reduce, сохранение в строку) задаётся порядок обхода в виде перестановки символов L, C, R (левый потомок, текущий элемент, правый потомок).

## Множество

Множество &#150; структура данных, реализующая математическое понятие множества.

Сравнение между множеством и очередью с приоритетом:

|Множество|Очередь с приоритетом|
|---------|---------------------|
|Содержит одиночные элементы|Содержит пары "ключ-элемент"|
|Неупорядочено|Упорядочена по возрастанию значения ключа (убыванию приоритета)|
|Поддерживает операции из теории множеств|Поддерживает вставку элемента и извлечение элемента с максимальным приоритетом|

Множество является удобным для работы с неупорядоченными наборами элементов, в частности, для множеств в математическом смысле. 

Абстрактный класс обладает публичными методами:

- Подсчёт количества элементов и проверка на пустоту
- Проверка на вхождение элемента
- Проверка на включение в множество
- Проверка на равенство множеств
- Операции над множествами: объединение, пересечение, разность
- Методы комплекса map-reduce
